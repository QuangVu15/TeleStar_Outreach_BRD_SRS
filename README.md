# Quang Vu — Business Analyst Portfolio

Static one-page portfolio. No build step.

## Deploy on GitHub Pages
1. Create a new public repository (e.g. `portfolio`).
2. Upload the contents of this folder: `index.html`, the `docs/` folder, and this README.
3. In the repo: Settings → Pages → Source = "Deploy from a branch" → Branch = `main` / root → Save.
4. Wait ~1 minute. Your site is live at `https://<your-username>.github.io/portfolio/`.

The "Open the BRD/SRS" button links to `docs/TeleStar_Outreach_BRD_SRS_EN.pdf` and works once deployed.
